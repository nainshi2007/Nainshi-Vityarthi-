# Student Result Management System

## Introduction

Student Result Management System is a simple Python based project
used to store and manage student marks and results.

The project is console based and uses basic Python concepts.

## Problem Statement

Managing student marks manually can take time and may lead to
calculation mistakes.

This project provides a simple system to enter student marks,
calculate results and display useful result information.

## Objectives

- Store student details and marks
- Calculate total marks
- Calculate percentage
- Calculate grade
- Search for a student
- Find the highest percentage
- Find class average

## Features

### 1. Add Student

The user can enter the student's name and marks in Python,
Maths and EVS.

### 2. Display Students

The system displays all students and their results.

### 3. Search Student

The user can search for a particular student by name.

### 4. Highest Percentage

The system finds the student with the highest percentage.

### 5. Class Average

The system calculates the average percentage of all students.
