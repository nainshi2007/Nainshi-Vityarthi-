# Project Statement

## Project Title

Student Result Management System

## Problem Statement

Managing student marks manually can be difficult when there are
multiple students. Calculating total marks, percentage and grades
manually can also result in mistakes.

The Student Result Management System provides a simple Python based
solution for managing student results.

## Scope of the Project

The project can be used to:

- Add student marks
- Display student results
- Search student records
- Calculate percentage
- Calculate grade
- Find highest percentage
- Calculate class average

The current project is a console-based application.

## Target Users

The project can be used by:

- Students
- Teachers
- Small educational institutions

## High-Level Features

1. Student Management
2. Result Calculation
3. Student Search
4. Result Analysis
5. Class Average Calculation
